# LSMS-ISA-harmonised-dataset-on-agricultural-productivity-and-welfare
This public repository was created to host a longitudinal cross-country dataset on agricultural productivity and welfare in Sub-Saharan Africa. The data and code can be found under [the latest release](https://github.com/lsms-worldbank/LSMS-ISA-harmonised-dataset-on-agricultural-productivity-and-welfare/releases/tag/v2.0).

This repository accompanies the following [working paper](https://documents.worldbank.org/en/publication/documents-reports/documentdetail/099422411182437399/idu199b0eff41783d144c71bf48140c83ca123a0), which provides a detailed description of the data and methodology. The working paper provides important context and should be referenced when using this repository. lease note that the paper was based on a previous dataset version (v1.1, available [here](https://github.com/lsms-worldbank/LSMS-ISA-harmonised-dataset-on-agricultural-productivity-and-welfare/releases/tag/v1.1), and does not include the latest additions, such as the Nigeria General Household Survey 2023/24.
